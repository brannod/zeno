ZENO 3.6.19 DISCORD GUIDE

1. Create a Discord application/bot in the Discord Developer Portal.
2. Enable Message Content Intent for the bot.
3. Invite it with View Channels, Send Messages, Read Message History,
   Add Reactions, Attach Files, and Embed Links.
4. Start Zeno once so zeno_data/private/DISCORD_TOKEN.txt is created.
5. Put your bot token and target channel ID in that private file.
6. Restart Zeno or use Reload Discord in Settings.

Discord is a chat interface to the same Zeno conversation/memory. Browser tools
remain controlled by the standalone GUI unless a specific Discord command is
implemented for that operation.

Zeno uses prefix commands only (for example `!help`); slash commands are not
registered or required.

Zeno keeps the complete shared Discord conversation in its local database.
Relevant older turns can be retrieved into later prompts, while the model's
finite context window remains protected by bounded excerpts and rolling summaries.

List comparison:
- `!comparelist` or `!listcompare` with exactly two attached text files lists
  entries shared by both lists (case-insensitive, trimmed matching).
- The duplicate report also lists repeated rows found inside List A or List B.
- `!listmissing` with exactly two attached text files lists entries found only
  in List A and only in List B.
- Large comparison results and large normal replies are sent as complete UTF-8
  `.txt` attachments instead of being truncated by Discord's message limit.

AYCD local card formatting (v3.6.19):
- !cardcolon       -> number:month:year:cvv
- !cardcolon5 TYPE -> type:number:month:year:cvv
Attach/reply to a text file. Formatted output is saved locally under Zeno Files -> Generated outputs and returned as a downloadable attachment; full values are not pasted into the message body.
