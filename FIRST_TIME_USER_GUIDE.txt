ZENO 3.6.19 — FIRST-TIME USER GUIDE
===================================

WINDOWS
-------
1. Install Python 3.11+ and make sure the Python launcher (`py`) works.
2. Run INSTALL_ZENO.bat. It installs dependencies and Chromium.
3. If using local models, launch LM Studio, load a model, and start its local
   server on port 1234.
4. Run START_ZENO.bat and open the displayed local URL if it does not open.

macOS
-----
1. Install Python 3.11+ from python.org or Homebrew.
2. Open Terminal, change directory to the Zeno folder, and run:
     chmod +x install_macos.sh start_macos.sh INSTALL_ZENO_MAC.command START_ZENO_MAC.command
     ./install_macos.sh
3. Start LM Studio on port 1234 if using local models.
4. Run ./start_macos.sh or double-click START_ZENO_MAC.command.
5. For Desktop Notetaker, grant Screen Recording permission when macOS asks.

FIRST SETTINGS
--------------
- Settings -> Models: choose Fast/Balanced and Deep models. Use Detect LM
  Studio models when the local server is running.
- Settings -> API Providers: enter an exact provider model ID and key, save it,
  then test it. A provider-side HTTP 4xx/5xx response is not automatically a
  bad key; read the returned status detail.
- Settings -> Zeno personality: edit how Zeno speaks in both the GUI and
  Discord. Use Classic Zeno or Reset default when you want the built-in prompt.
- Settings -> Context & memory: automatic memory, rolling summaries, and full
  conversation archive retrieval are enabled by default. The database keeps
  the complete transcript; only relevant older excerpts enter each prompt.
- Settings -> Context & memory: automatic memory, rolling summaries, and full
  conversation archive retrieval are enabled by default. The database keeps
  the complete transcript; only relevant older excerpts enter each prompt.
- Files -> AYCD / MCP tools: configure AYCD only if its MCP endpoint is running.
- Settings -> Zeno Updates: confirm the repository is brannod/zeno.

FILES AND FILE WORKER
---------------------
Files -> File Worker supports either an uploaded text file or pasted text.
Pasted text is saved locally as the source for the reviewed job. Choose a
preset, add optional rules, click Preview, inspect the result, then click Run
approved preview. Jobs are cancellable and validated before output delivery.
List Compare accepts two pasted lists or two uploaded text files. Use Find
duplicates for shared entries, or Find missing for entries present on only one
side.

DISCORD LIST TOOLS
------------------
Attach two text files to one message and use `!comparelist` (or `!listcompare`)
to list shared entries, or `!listmissing` to list entries unique to each file.
Discord uses prefix commands only. Oversized replies are delivered as .txt
files so complete output is preserved. File transforms return a downloadable
attachment; sensitive card values are kept out of the message body.

SAFETY AND DATA
---------------
Zeno stores chats in memory/zeno.db. Uploads, generated files, screenshots,
browser state, API provider keys, Discord settings, and MCP keys remain under
zeno_data/. Back up those folders before upgrades or moving Zeno to another
computer. Never paste API keys into chat or public issue reports.

TROUBLESHOOTING
---------------
- `ModuleNotFoundError: config`: use an official release asset, not GitHub's
  Code -> Download ZIP source snapshot. The release contains config.py.
- `LM Studio is unreachable`: start its local server and confirm port 1234.
- QuartzRouter Cloudflare 403/502: the request reached QuartzRouter; the
  provider or its upstream route must allow/fix the request.
- Browser or PDF unavailable: rerun the platform install script, then restart.
- macOS desktop capture blocked: allow Screen Recording for Terminal/Python or
  Zeno under System Settings -> Privacy & Security.
