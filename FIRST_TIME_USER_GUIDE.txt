ZENO 3.0 FIRST-TIME GUIDE

Run INSTALL_ZENO.bat, start the LM Studio local server on port 1234, then run
START_ZENO.bat. Use Fast or Balanced for everyday work. Select Deep only when
you explicitly want the configured deep model.

The GUI has Chat, Browser, DeepSearch, Files, Memory, and Settings areas.
DeepSearch supports up to 1,000 pages. The Files panel can clear all uploaded
input files while preserving generated outputs. Browser/DeepSearch/Screen Reader
jobs can be stopped without stopping the entire application.

Discord is optional. Put its token/channel information in the private
DISCORD_TOKEN.txt created by Zeno, then reload the Discord bridge in Settings.
Never share that token file.
